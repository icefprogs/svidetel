# Security

Svidetel is a preview Windows inspection tool, not a security boundary or antivirus.
Do not publish private inventory reports. Report vulnerabilities using GitHub private
vulnerability reporting when enabled, or contact the maintainer through their profile
to arrange private disclosure.

Trust the application directory, Bridge.ps1 and local journal. Do not run an elevated
copy from a shared writable folder or restore a journal obtained from another person.
Missing signatures do not prove malware. Review dependencies before disabling services.
